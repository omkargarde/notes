My advice for learning most of what you'd need as a frontend developer (for FREE):

1. @iliakan
   's http://javascript.info for the basics and some not so basic stuff. (mostly important IMO)

2. Once you know JS, move on to understanding how modern browsers work, some relevant blogs:

- https://web.dev/articles/howbrowserswork (pretty old, but amazing at how relevant it still is)
- https://developer.mozilla.org/en-US/docs/Web/Performance/How_browsers_work

3. Follow that up with
   @philip_roberts
   's evergreen talk - at
   @jsconfeu
   https://2014.jsconf.eu/speakers/philip-roberts-what-the-heck-is-the-event-loop-anyway.html

4. @5t3ph
   's Foundations Series covers the basics of HTML and CSS! https://learnfromsteph.dev/#schedule

5. (Optional) Get good at CSS - I'm a fan of https://moderncss.dev (also by
   @5t3ph
   )

6. Now that you know how a browser parses a web page, try to learn the basics of bundlers
   @dsalinasgardon
   has an easy to follow along blog here: https://snipcart.com/blog/javascript-module-bundler

7. Follow that up by finishing the flexbox froggy by
   @playcodepip
   : https://flexboxfroggy.com (Be good at being able to place elements anywhere you like)

8. Spend some time building React apps: (any one)

- @bobziroll
  's https://scrimba.com/learn/learnreact
- @kentcdodds
  's https://egghead.io/courses/the-beginner-s-guide-to-react
- or
  @james_k_nelson
  's https://frontarm.com/courses/react-fundamentals/

9. Some interesting bits on performance from
   @Google

- https://web.dev/learn/performance
